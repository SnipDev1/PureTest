PureTestImage — Руководство по тестам и настройке без пересборки
================================================================

Раздел `DATADISK` (FAT32) — центр управления тестами:
При подключении флешки к Windows этот раздел монтируется как обычный диск.
ВСЕ изменения тестов, списков автозапуска и настроек делаются прямо на нем.
ПЕРЕСОБИРАТЬ ОБРАЗ СИСТЕМЫ НЕ ТРЕБУЕТСЯ!

Структура раздела DATADISK:
---------------------------
    DATADISK/
        AUTORUN                Список тестов для автозапуска при включении
        run_list.txt           Список тестов для запуска через меню [l]
        config.env             Файл настроек (RUNS, TIMEOUT, FLAGS, AFTER_AUTORUN)
        runner.sh              ОПЦИОНАЛЬНО: переопределение логики меню/раннера
        tests/
            cpu_checkmate/     Тест CPU: 16-Queens SIMD (AIDA64 CheckMate)
            fpu_mandel/        Тест FPU: 64-bit Mandelbrot (AIDA64 Mandel)
            bench_cpu/         Комплексный CPU/FPU/Memory чек
            usb_check/         Аудит шины и портов USB
            usb_bench/         Замер скорости USB накопителя
            ...
        results/               Автоматически создается: отчеты о прогонах

Структура каждого теста (DATADISK/tests/<имя теста>/):
------------------------------------------------------
    *.cpp  *.cc  *.cxx     исходные коды (компилируются на тестируемой машине)
    build.flags            ОПЦИОНАЛЬНО: доп. флаги g++, одна строка
    run.sh                 ОПЦИОНАЛЬНО: bash-скрипт вместо компилируемого C++
    run.args               ОПЦИОНАЛЬНО: аргументы командной строки
    run.stdin              ОПЦИОНАЛЬНО: файл, передаваемый в stdin

Как настраивать запуск тестов без пересборки:
--------------------------------------------
1. ВЫБОР ТЕСТОВ ДЛЯ ЗАПУСКА:
   Создайте файл `DATADISK/AUTORUN` или `DATADISK/run_list.txt`.
   В нем перечислите нужные тесты по одному на строку (или через пробел/запятую):
       cpu_checkmate
       fpu_mandel
       # bench_cpu
   Если указать `ALL` — запустятся абсолютно все доступные тесты.
   Строки с `#` и пустые строки игнорируются.

2. ФАЙЛ НАСТРОЕК (DATADISK/config.env):
   Вы можете регулировать любые параметры прогона прямо из Windows:
       RUNS=3                      # Количество повторений теста (по умолчанию 3)
       TIMEOUT=600                 # Лимит времени на прогон, секунд
       FLAGS="-O2 -march=native"   # Базовые флаги g++
       GOVERNOR=performance        # Режим частоты CPU (performance, powersave)
       AFTER_AUTORUN=poweroff      # Что делать после тестов: poweroff, menu, reboot, shell

3. ИЗМЕНЕНИЕ ИСХОДНИКОВ ТЕСТОВ:
   Просто отредактируйте `.cpp` или `build.flags` в блокноте / VS Code на флешке.
   При загрузке система сама перекомпилирует обновленный код на целевом процессоре!

4. ИЗМЕНЕНИЕ САМОГО РАННЕРА / МЕНЮ (OVERRIDE):
   Если вам нужно изменить поведение самого меню, добавить свои команды или утилиты:
   Положите отредактированный `runner.sh` прямо в корень `DATADISK/`.
   Система при старте обнаружит его и передаст управление ему вместо встроенного в образ!

Управление в интерактивном меню:
--------------------------------
  [a] Запуск ВСЕХ доступных тестов по очереди (пакетный режим)
  [l] Запуск списка тестов из run_list.txt / AUTORUN
  [s] Выход в интерактивную root-консоль (bash)
  [c] Очистить экран
  [r] Перезагрузка (reboot)
  [p] Выключение (poweroff)
  Или введите имя конкретного теста для единичного прогона.
