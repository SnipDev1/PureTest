================================================================================
Практическое задание № 1: Определение времени работы прикладных программ
Кафедра прикладной математики НГТУ
================================================================================

Данный тест демонстрирует сравнение двух вариантов вычисления функции e^x:
  * base.cpp — без алгоритмической оптимизации (O(N^2))
  * opt.cpp  — с алгоритмической оптимизацией (схема Горнера, O(N))
  * inputs.txt — сетка значений x и n

Запуск в меню PureTest:
  [lab] -> выбрать 'lab1_exp'
  или ввести: lab lab1_exp

Раннер автоматически:
  1. Скомпилирует оба варианта под степенями оптимизации O0, O1, O2.
  2. Прогонит их по всем параметрам из inputs.txt.
  3. Сравнит результат вычисления с математическим эталоном exp(x).
  4. Сформирует 3 готовые таблицы для копирования в Microsoft Word:
       - accuracy_table.tsv (Таблица точности вычислений)
       - timing_table.tsv   (Таблица времени работы и выигрыша в %)
       - machine_specs.tsv  (Паспорт архитектуры компьютера)
================================================================================
