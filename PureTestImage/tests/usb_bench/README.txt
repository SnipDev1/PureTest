usb_bench — Замер реальной скорости чтения и записи USB-накопителя
===================================================================

Что делает тест:
1. Выполняет тест последовательной записи (64 МиБ блоками по 1 МиБ)
   на раздел DATADISK с обязательным fsync() на физический флеш.
2. Сбрасывает страничный кэш ядра Linux (posix_fadvise POSIX_FADV_DONTNEED)
   и замеряет скорость последовательного чтения (64 МиБ блоками по 1 МиБ).
3. Проводит случайное чтение 4K блоками (500 операций) для замера IOPS
   и средней задержки доступа (latency в мс).
4. Удаляет временный тестовый файл и выполняет sync().
5. Выводит понятную сводку (MiB/s, IOPS, класс скорости: USB 3.0 SSD vs USB 2.0).
