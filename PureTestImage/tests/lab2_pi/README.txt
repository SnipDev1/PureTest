================================================================================
Практическое задание: Вычисление числа Пи по ряду Лейбница
Формула: pi = 4 * sum_{n=0}^{N-1} ((-1)^n / (2*n + 1))
================================================================================

Данный лабораторный тест демонстрирует сравнение двух вариантов реализации:
  * base.cpp — без алгоритмической оптимизации (O(N^2))
      Знак (-1)^n вычисляется в цикле в отдельной подпрограмме summand(n).
  * opt.cpp  — с алгоритмической оптимизацией (O(N))
      Знак переключается одной операцией (sign = -sign), знаменатель
      накапливается сложением (denom += 2.0), умножение на 4 вынесено
      за цикл.
  * inputs.txt — сетка значений N (число членов ряда).

Запуск в меню PureTest:
  [lab] -> выбрать 'lab2_pi'
  или ввести в консоли: lab lab2_pi

Результаты:
  * accuracy_table.tsv — оценка погрешности относительно pi = 3.1415926535...
  * timing_table.tsv   — таблица времени и выигрыша (%) по уровням O0, O1, O2
  * machine_specs.tsv  — паспорт аппаратной архитектуры ПК
================================================================================
